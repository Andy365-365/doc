第二部分 src/gateway/agent-prompt.ts编辑于 2026-05-03 17:21・北京 #

这个程序的职责是：把一段对话历史组装成发给 LLM 的消息字符串。它是 Gateway 层把"用户对话"翻译成"模型输入"的关键桥梁。

import { buildHistoryContextFromEntries, type HistoryEntry } from "../auto-reply/reply/history.js";
import { extractTextFromChatContent } from "../shared/chat-content.js";
/**
* 引入了两个外部能力：
* buildHistoryContextFromEntries — 负责把历史条目格式化成带上下文的字符串
* extractTextFromChatContent — 负责从复杂的 content 结构里提取纯文本
* HistoryEntry — 单条历史记录的类型定义（只引入类型，不引入运行时值）
**/
export type ConversationEntry = {
  role: "user" | "assistant" | "tool";
  entry: HistoryEntry;
};
/**
这个文件自己定义的类型，对 HistoryEntry 做了一层包装，增加了 role 字段。
role 只有三种值，用可辨识联合而不是 string（符合 AGENTS.md 里的代码规范）。
继承了HistroyEntry
**/
/**
 * Coerce body to string. Handles cases where body is a content array
 * (e.g. [{type:"text", text:"hello"}]) that would serialize as
 * [object Object] if used directly in a template literal.
 */
function safeBody(body: unknown): string {
  if (typeof body === "string") {
    return body;
  }
  return extractTextFromChatContent(body) ?? "";
}
/**
这个小函数解决了一个实际的运行时陷阱。
问题根源： 现代 LLM API（OpenAI、Anthropic 等）的消息 content 有两种格式：
// 格式一：纯字符串
body = "你好"

// 格式二：content 数组（多模态消息）
body = [
  { type: "text",  text: "你好" },
  { type: "image", url: "..." }
]
如果直接把格式二放进模板字符串 `${body}`，JavaScript 会调用 .toString()，输出 [object Object]，
而不是文本内容。
**/

export function buildAgentMessageFromConversationEntries(entries: ConversationEntry[]): string {
  if (entries.length === 0) {
    return "";
  }
/**
这是这个文件唯一导出的函数，也是最核心的逻辑。它接收一段对话历史，返回一个组装好的字符串，直接交给 LLM。
没有条目就没有消息，早退。
**/

  // Prefer the last user/tool entry as "current message" so the agent responds to
  // the latest user input or tool output, not the assistant's previous message.
//从后往前扫描，找最后一条 role === "user" 或 role === "tool" 的条目，把它当作"当前需要回复的消息"。  
let currentIndex = -1;
  for (let i = entries.length - 1; i >= 0; i -= 1) {
    const role = entries[i]?.role;
    if (role === "user" || role === "tool") {
      currentIndex = i;
      break;
    }
  }

//如果全是 assistant 条目（极端情况），就取最后一条，总比返回空好。  
if (currentIndex < 0) {
    currentIndex = entries.length - 1;
  }

//组装最终字符串  
const currentEntry = entries[currentIndex]?.entry;
  if (!currentEntry) {
    return "";
  }

  const historyEntries = entries.slice(0, currentIndex).map((e) => e.entry);
  if (historyEntries.length === 0) {
    return safeBody(currentEntry.body);
  }

  const formatEntry = (entry: HistoryEntry) => `${entry.sender}: ${safeBody(entry.body)}`;
  return buildHistoryContextFromEntries({
    entries: [...historyEntries, currentEntry],
    currentMessage: formatEntry(currentEntry),
    formatEntry,
  });
}

3.http服务层 #

这是一个典型的 生产级服务器启动函数 ，考虑了实际部署中可能遇到的各种问题。

import type { Server as HttpServer } from "node:http";
import { GatewayLockError } from "../../infra/gateway-lock.js";
import { sleep } from "../../utils.js";
//两个常量把"重试 4 次，每次间隔 500ms"从逻辑中剥离出来单独管理，便于调参。
const EADDRINUSE_MAX_RETRIES = 4;
const EADDRINUSE_RETRY_INTERVAL_MS = 500;
//
async function closeServerQuietly(httpServer: HttpServer): Promise<void> {
  await new Promise<void>((resolve) => {
    try {
      httpServer.close(() => resolve());
    } catch {
      resolve();
    }
  });
}

export async function listenGatewayHttpServer(params: {
//export 是 JavaScript/TypeScript 中 模块系统 的核心关键字，用于将一个模块中的内容（变量、函数、类、类型等） 
//暴露给其他模块使用 。
  httpServer: HttpServer;
  bindHost: string;
  port: number;
}) {
  const { httpServer, bindHost, port } = params;
//这不是传统的有界循环，而是一个靠 return 或 throw 强制退出的无限循环，等价于 while (true)，
但可以方便地跟踪 attempt 计数器。

  for (let attempt = 0; ; attempt++) {
    try {
      await new Promise<void>((resolve, reject) => {
        const onError = (err: NodeJS.ErrnoException) => {
          httpServer.off("listening", onListening);
          reject(err);
        };
        const onListening = () => {
          httpServer.off("error", onError);
          resolve();
        };
        httpServer.once("error", onError);
        httpServer.once("listening", onListening);
        httpServer.listen(port, bindHost);
      });
      return; // bound successfully
    } catch (err) {
      const code = (err as NodeJS.ErrnoException).code;
      if (code === "EADDRINUSE" && attempt < EADDRINUSE_MAX_RETRIES) {
        // Port may still be in TIME_WAIT after a recent process exit; retry.
        await closeServerQuietly(httpServer);
        await sleep(EADDRINUSE_RETRY_INTERVAL_MS);
        continue;
      }
      if (code === "EADDRINUSE") {
        throw new GatewayLockError(
          `another gateway instance is already listening on ws://${bindHost}:${port}`,
          err,
        );
      }
      throw new GatewayLockError(
        `failed to bind gateway socket on ws://${bindHost}:${port}: ${String(err)}`,
        err,
      );
    }
  }
}

4.http-auth.ts #

这个文件是 OpenClaw 网关的 Canvas（可视化/交互界面） HTTP 请求认证模块 ，专门处理 Canvas 相关路径的认证。

import type { IncomingMessage } from "node:http";
import { A2UI_PATH, CANVAS_HOST_PATH, CANVAS_WS_PATH } from "../../canvas-host/a2ui.js";
import { safeEqualSecret } from "../../security/secret-equal.js";
import type { AuthRateLimiter } from "../auth-rate-limit.js";
import {
  authorizeHttpGatewayConnect,
  type GatewayAuthResult,
  type ResolvedGatewayAuth,
} from "../auth.js";
import { CANVAS_CAPABILITY_TTL_MS } from "../canvas-capability.js";
import { getBearerToken, resolveHttpBrowserOriginPolicy } from "../http-auth-utils.js";
import type { GatewayWsClient } from "./ws-types.js";
/**
功能 ：判断一个 URL 路径是否属于 Canvas 相关路径

匹配的路径类型 ：

- A2UI_PATH - A2UI（Agent to UI）路径
- A2UI_PATH/* - A2UI 的子路径
- CANVAS_HOST_PATH - Canvas 宿主路径
- CANVAS_HOST_PATH/* - Canvas 宿主的子路径
- CANVAS_WS_PATH - Canvas WebSocket 路径
使用场景 ：在网关路由时，快速判断是否需要应用 Canvas 特殊认证逻辑
**/

export function isCanvasPath(pathname: string): boolean {
  return (
    pathname === A2UI_PATH ||
    pathname.startsWith(`${A2UI_PATH}/`) ||
    pathname === CANVAS_HOST_PATH ||
    pathname.startsWith(`${CANVAS_HOST_PATH}/`) ||
    pathname === CANVAS_WS_PATH
  );
}
/**
Canvas 能力验证函数： hasAuthorizedWsClientForCanvasCapability
遍历所有 WebSocket 客户端
    ↓
检查客户端是否有 canvasCapability
    ↓
检查是否已过期 (canvasCapabilityExpiresAtMs)
    ↓
使用安全比较 (safeEqualSecret) 验证能力令牌
    ↓
验证成功 → 滑动更新过期时间 → 返回 true
    ↓
没有匹配的客户端 → 返回 false
**/
function hasAuthorizedWsClientForCanvasCapability(
  clients: Set<GatewayWsClient>,
  capability: string,
): boolean {
  const nowMs = Date.now();
  for (const client of clients) {
    if (!client.canvasCapability || !client.canvasCapabilityExpiresAtMs) {
      continue;
    }
    if (client.canvasCapabilityExpiresAtMs <= nowMs) {
      continue;
    }
    if (safeEqualSecret(client.canvasCapability, capability)) {
      // Sliding expiration while the connected node keeps using canvas.
      client.canvasCapabilityExpiresAtMs = nowMs + CANVAS_CAPABILITY_TTL_MS;
      return true;
    }
  }
  return false;
}
/**
主认证函数： authorizeCanvasRequest
开始认证
    ↓
┌─────────────────────────────────────┐
│ 1. 快速失败：路径格式错误？         │
│    malformedScopedPath === true     │
│    ↓                                 │
│    返回 { ok: false, reason: "unauthorized" } │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 2. 尝试 Bearer Token 认证           │
│    从请求中提取 token                │
│    ↓                                 │
│    有 token？                        │
│    ├─ 是 → 调用 authorizeHttpGatewayConnect │
│    │      ↓                          │
│    │   认证成功？                    │
│    │   ├─ 是 → 返回认证成功         │
│    │   └─ 否 → 记录失败，继续       │
│    └─ 否 → 继续下一认证方式         │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 3. 尝试 Canvas 能力认证              │
│    有 canvasCapability？             │
│    ↓                                 │
│    调用 hasAuthorizedWsClientForCanvasCapability │
│    ↓                                 │
│    找到有效客户端？                   │
│    ├─ 是 → 返回认证成功              │
│    └─ 否 → 继续                      │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 4. 所有认证方式都失败                │
│    返回最后一次失败或默认未授权      │
└─────────────────────────────────────┘
**/
export async function authorizeCanvasRequest(params: {
  req: IncomingMessage;
  auth: ResolvedGatewayAuth;
  trustedProxies: string[];
  allowRealIpFallback: boolean;
  clients: Set<GatewayWsClient>;
  canvasCapability?: string;
  malformedScopedPath?: boolean;
  rateLimiter?: AuthRateLimiter;
}): Promise<GatewayAuthResult> {
  const {
    req,
    auth,
    trustedProxies,
    allowRealIpFallback,
    clients,
    canvasCapability,
    malformedScopedPath,
    rateLimiter,
  } = params;
  if (malformedScopedPath) {
    return { ok: false, reason: "unauthorized" };
  }

  let lastAuthFailure: GatewayAuthResult | null = null;
  const token = getBearerToken(req);
  if (token) {
    const authResult = await authorizeHttpGatewayConnect({
      auth: { ...auth, allowTailscale: false },
      connectAuth: { token, password: token },
      req,
      trustedProxies,
      allowRealIpFallback,
      rateLimiter,
      browserOriginPolicy: resolveHttpBrowserOriginPolicy(req),
    });
    if (authResult.ok) {
      return authResult;
    }
    lastAuthFailure = authResult;
  }

  if (canvasCapability && hasAuthorizedWsClientForCanvasCapability(clients, canvasCapability)) {
    return { ok: true };
  }
  return lastAuthFailure ?? { ok: false, reason: "unauthorized" };
}

import { randomUUID } from "node:crypto";
import { sanitizeInboundSystemTags } from "../../auto-reply/reply/inbound-text.js";
import type { CliDeps } from "../../cli/deps.types.js";
import { getRuntimeConfig } from "../../config/io.js";
import {
  resolveAgentMainSessionKey,
  resolveMainSessionKey,
  resolveMainSessionKeyFromConfig,
} from "../../config/sessions.js";
import type { OpenClawConfig } from "../../config/types.openclaw.js";
import type { RunCronAgentTurnResult } from "../../cron/isolated-agent/run.types.js";
import type { CronJob } from "../../cron/types.js";
import { requestHeartbeat } from "../../infra/heartbeat-wake.js";
import { enqueueSystemEvent } from "../../infra/system-events.js";
import type { createSubsystemLogger } from "../../logging/subsystem.js";
import { normalizeOptionalString } from "../../shared/string-coerce.js";
import { type HookAgentDispatchPayload, type HooksConfigResolved } from "../hooks.js";
import { createHooksRequestHandler, type HookClientIpConfig } from "./hooks-request-handler.js";

type SubsystemLogger = ReturnType<typeof createSubsystemLogger>;

/**
 * 解析 Hook 事件应该使用的会话密钥
 * @param params - 参数对象
 * @param params.cfg - OpenClaw 配置
 * @param params.agentId - 可选的 Agent ID
 * @returns 会话密钥
 */
function resolveHookEventSessionKey(params: { cfg: OpenClawConfig; agentId?: string }): string {
  return params.agentId
    ? resolveAgentMainSessionKey({ cfg: params.cfg, agentId: params.agentId })
    : resolveMainSessionKey(params.cfg);
}

/**
 * 判断是否应该宣布 Hook 运行结果
 * @param params - 参数对象
 * @param params.deliver - 是否需要交付
 * @param params.result - Agent 执行结果
 * @returns 是否应该宣布
 */
function shouldAnnounceHookRunResult(params: {
  deliver: boolean;
  result: RunCronAgentTurnResult;
}): boolean {
  // 如果执行失败，总是宣布
  if (params.result.status !== "ok") {
    return true;
  }
  // 如果需要交付但既没有交付也没有尝试交付，则宣布
  return (
    params.deliver && params.result.delivered !== true && params.result.deliveryAttempted !== true
  );
}

/**
 * 创建网关 Hook 请求处理器的工厂函数
 * @param params - 参数对象
 * @param params.deps - CLI 依赖对象
 * @param params.getHooksConfig - 获取 Hook 配置的函数
 * @param params.getClientIpConfig - 获取客户端 IP 配置的函数
 * @param params.bindHost - 绑定的主机地址
 * @param params.port - 监听的端口
 * @param params.logHooks - Hook 子系统日志记录器
 * @returns Hook 请求处理器
 */
export function createGatewayHooksRequestHandler(params: {
  deps: CliDeps;
  getHooksConfig: () => HooksConfigResolved | null;
  getClientIpConfig: () => HookClientIpConfig;
  bindHost: string;
  port: number;
  logHooks: SubsystemLogger;
}) {
  const { deps, getHooksConfig, getClientIpConfig, bindHost, port, logHooks } = params;

  /**
   * 分派唤醒类型的 Hook
   * @param value - 参数对象
   * @param value.text - 要发送的文本
   * @param value.mode - 唤醒模式："now"（立即）或 "next-heartbeat"（下次心跳）
   */
  const dispatchWakeHook = (value: { text: string; mode: "now" | "next-heartbeat" }) => {
    // 解析主会话密钥
    const sessionKey = resolveMainSessionKeyFromConfig();
    // 将文本加入系统事件队列，标记为不可信
    enqueueSystemEvent(value.text, { sessionKey, trusted: false });
    // 如果模式是 "now"，立即请求心跳唤醒
    if (value.mode === "now") {
      requestHeartbeat({ source: "hook", intent: "immediate", reason: "hook:wake" });
    }
  };

  /**
   * 分派 Agent 类型的 Hook（核心功能）
   * @param value - Hook Agent 分派参数
   * @returns 运行 ID
   */
  const dispatchAgentHook = (value: HookAgentDispatchPayload) => {
    // 获取会话密钥
    const sessionKey = value.sessionKey;
    // 清理 Hook 名称，移除系统标签
    const safeName = sanitizeInboundSystemTags(value.name);
    // 生成唯一的 Job ID 和 Run ID
    const jobId = randomUUID();
    const runId = randomUUID();
    // 记录当前时间
    const now = Date.now();

    // 创建交付配置
    const delivery = value.deliver
      ? {
          mode: "announce" as const,
          channel: value.channel,
          to: value.to,
        }
      : { mode: "none" as const };

    // 创建 CronJob 对象（虽然叫 Cron，但这里是立即执行）
    const job: CronJob = {
      id: jobId,
      agentId: value.agentId,
      name: safeName,
      enabled: true,
      createdAtMs: now,
      updatedAtMs: now,
      // 使用 "at" 类型，立即执行
      schedule: { kind: "at", at: new Date(now).toISOString() },
      // 隔离会话，不影响主会话
      sessionTarget: "isolated",
      wakeMode: value.wakeMode,
      // Agent 执行的完整参数
      payload: {
        kind: "agentTurn",
        message: value.message,
        model: value.model,
        thinking: value.thinking,
        timeoutSeconds: value.timeoutSeconds,
        allowUnsafeExternalContent: value.allowUnsafeExternalContent,
        externalContentSource: value.externalContentSource,
      },
      delivery,
      state: { nextRunAtMs: now },
    };

    // Hook 事件会话密钥（在异步块中设置）
    let hookEventSessionKey: string | undefined;

    // 异步执行 Agent（即发即弃模式）
    void (async () => {
      try {
        // 获取运行时配置
        const cfg = getRuntimeConfig();
        // 解析 Hook 事件会话密钥
        hookEventSessionKey = resolveHookEventSessionKey({
          cfg,
          agentId: value.agentId,
        });

        // 懒加载：动态导入 Cron 隔离 Agent 模块
        const { runCronIsolatedAgentTurn } = await import("../../cron/isolated-agent.js");

        // 执行 Agent
        const result = await runCronIsolatedAgentTurn({
          cfg,
          deps,
          job,
          message: value.message,
          sessionKey,
          lane: "cron",
        });

        // 生成执行摘要（按优先级选择）
        const summary =
          normalizeOptionalString(result.summary) ||
          normalizeOptionalString(result.error) ||
          result.status;

        // 生成消息前缀
        const prefix =
          result.status === "ok" ? `Hook ${safeName}` : `Hook ${safeName} (${result.status})`;

        // 判断是否需要宣布结果
        const shouldAnnounce = shouldAnnounceHookRunResult({ deliver: value.deliver, result });

        if (shouldAnnounce) {
          // 需要宣布：加入系统事件队列
          const eventSessionKey = hookEventSessionKey ?? resolveMainSessionKeyFromConfig();
          enqueueSystemEvent(`${prefix}: ${summary}`.trim(), {
            sessionKey: eventSessionKey,
            trusted: false,
          });
          // 如果是立即唤醒模式，请求心跳
          if (value.wakeMode === "now") {
            requestHeartbeat({ source: "hook", intent: "immediate", reason: `hook:${jobId}` });
          }
        } else if (result.status === "ok" && !value.deliver) {
          // 不需要宣布但执行成功：记录日志
          logHooks.info("hook agent run completed without announcement", {
            sourcePath: value.sourcePath,
            name: safeName,
            runId,
            jobId,
            agentId: value.agentId,
            sessionKey,
            completedAt: new Date().toISOString(),
          });
        }
      } catch (err) {
        // 错误处理
        logHooks.warn(`hook agent failed: ${String(err)}`);
        // 将错误加入系统事件队列
        enqueueSystemEvent(`Hook ${safeName} (error): ${String(err)}`, {
          sessionKey: hookEventSessionKey ?? resolveMainSessionKeyFromConfig(),
          trusted: false,
        });
        // 如果是立即唤醒模式，请求心跳
        if (value.wakeMode === "now") {
          requestHeartbeat({
            source: "hook",
            intent: "immediate",
            reason: `hook:${jobId}:error`,
          });
        }
      }
    })();

    // 立即返回 Run ID，不等待异步执行完成
    return runId;
  };

  // 创建并返回 Hook 请求处理器
  return createHooksRequestHandler({
    getHooksConfig,
    bindHost,
    port,
    logHooks,
    getClientIpConfig,
    dispatchAgentHook,
    dispatchWakeHook,
  });
}

openclaw 2026.5.4 飞书文档创建的bug

Openclaw2026.5.4的飞书文档创建bug分析编辑于 2026-05-07 16:25・北京 #

openclaw创建飞书文档是我经常使用的工具，这个工具由飞书插件提供，在2026.5.x之后，Openclaw一直存在无法创建文档bug，直接的原因是Openclaw运行时飞书插件的工具没有进入工具列表。

我对2026.5.4版本的openclaw进行了追查，找到了一个openclaw的渠道解析的bug。

Openclaw调用飞书插件工具的机制 #

Openclaw在加载飞书插件的工具，如创建飞书文档、读写飞书文档是有条件加载，只有飞书渠道发起的任务才会加载该工具列表，问题就出在Openclaw在解析sessionKey识别渠道时出现bug，导致无法正确识别飞书渠道。

根本原因：SessionKey 解析逻辑 Bug #

实际 SessionKey 格式（Direct Message）：

agent:main:feishu:main:direct:<我的用户id>
          ↑      ↑     ↑      ↑      ↑
        agentId channel accountId kind userId

结构：agent:{agentId}:{channel}:{accountId}:{kind}:{userId}

openclaw解析代码假设的格式：

agent:main:feishu:group:group_id
          ↑      ↑     ↑      ↑
        agentId channel kind groupId

Openclaw解析代码与实际sessionKey格式不一致，导致解析结果错误

解析结果：
parts[0] = "feishu" ✓
parts[1] = "main" ← 误认为是 kind
parts[2] = "direct" ← 真正的 kind 被忽略

而Openclaw在加载工具时，有如下的判断逻辑

if (kind !== "group" && kind !== "channel") return null;

因为 kind = "main" 既不是 "group" 也不是 "channel"，函数返回 null。

影响范围

  1. Direct Message 无法正确解析 → groupPolicy = null
  2. 工具 allowlist 未包含飞书工具 → feishu_doc 等工具不可用
  3. 所有飞书 Direct Message 会话受影响

代码位置

问题文件：
~/.nvm/versions/node/v24.13.1/lib/node_modules/openclaw/dist/tools-gW9A7NO2.js

问题函数：

function parseSessionKeyForPolicy(sessionKey) {
    const body = sessionKey.split(":").slice(2);  // 去掉 "agent:main:"
    const channel = body[0];  // "feishu"
    const kind = body[1];      // "main" ← Bug! 应该是 "direct"
    // ...
    if (kind !== "group" && kind !== "channel") return null;
}

修复方案 #

修改 SessionKey 解析逻辑：

function parseSessionKeyForPolicy(sessionKey) {
    const parts = sessionKey.split(":");
    // agent:{agentId}:{channel}:{accountId}:{kind}:{userId}
    // 或 agent:{agentId}:{channel}:{kind}:{groupId}
    
    const channel = parts[2];
    
    // 判断格式：
    // - Direct: 6 段，parts[4] = "direct"
    // - Group: 5 段，parts[3] = "group"
    
    if (parts.length === 6 && parts[4] === "direct") {
        return {
            channel,
            kind: "direct",
            userId: parts[5],
            accountId: parts[3]
        };
    } else if (parts.length === 5 && parts[3] === "group") {
        return {
            channel,
            kind: "group",
            groupId: parts[4]
        };
    }
    
    return null;
}
