本地算力

构建一台单插座四卡 GPU 工作站

作者：Joe Barrow / 2026-05-18 原文

读研究生时，我梦寐以求的就是拥有一台 GPU 工作站。如今工作有了收入，终于能圆梦了。

TL;DR

我搭了一台 4 卡 3090 Ti 的工作站，这样你就不用自己折腾了。当然——如果你就是想去折腾，那还是建议你把全文读完！

过去几个月，我一点一点地攒出了一台多 GPU 工作站，并确保它能只靠一个标准美式墙壁插座供电。靠这台机器，我训练了 DETR 模型（面向 CommonForms 数据集）、一个 13 亿参数的 VLM（同样基于 CommonForms），还为 LOCUS-v1 数据集 完成了首批一百万页法律的 OCR 处理。

硬性约束

  1. 必须仅靠一个标准美式墙壁插座运行 —— 15A、120V。这条没有商量余地：我租的公寓没法改线路，也不能新增大功率回路。
  2. 不能造成生活困扰 —— 我不是一个人住，机器不能太吵或太热。
  3. 预算必须合理 —— 对"合理"的定义因人而异，后文会详细列出花费。只看前两条约束的话，我完全可以花 6 万美元搭一套更牛的配置，但那已经超出我的定义了。
  4. 必须有足够的 VRAM 和算力来 SFT / RL 高质量的视觉语言模型 —— 这就是我折腾这一切的根本原因。

最初的计划

方案很简单：买一块服务器主板，要有足够的 PCIe x16 插槽；搭配一颗 PCIe 通道数够多的 CPU；尽可能塞满便宜的 DDR4 内存和 SSD。然后把 GPU 的功耗限制到合理范围，开跑实验就行了。

现实的耳光

Everybody has a plan until they get punched in the face.

—— Mike Tyson

不幸的是，Mike Tyson 说得对。在搭建工作站的过程中，我的计划改了好几次。

硬件挤兑

如果你过去一年关注过电脑硬件的价格，就知道我的计划是怎么翻车的。内存价格翻了五倍，SSD 翻了三倍，二手 GPU 更是暴涨。

买便宜的二手服务器配件已不再可行。要找到合理的硬件价格，得花大量时间和耐心在 eBay、r/homelabsales 和 r/hardwareswap 上淘货。判断一个零件"到底算不算好价"变得非常困难，我只能退而求其次，用秘书问题（Secretary Problem）的思维来决策：给定最近一次的成交参考价和自己的心理上限，眼前这个价格值不值得直接拍？

二手件风险

这台机器除第一张 3090 Ti 外，全是二手件。二手配件有独特的风险：这块硬盘是不是已经废了？GPU 有没有暗病？卖家是不是骗子？

我运气还算不错，只有一次订了 3090 Ti 结果收到 3090 的插曲。卖家回复很及时，最后给我退了款。但这种风险就是游戏的一部分，你得接受。

功率限制的真相

如果只想用单一插座供电，功率限制是你的救命稻草。但遗憾的是，这个朋友不靠谱，还撒谎。

运行 nvidia-smi -pl 250 并不会把 GPU 严格锁死在 250W，而是将每毫秒内的平均功耗限制到 250W。GPU 在那一毫秒内可以有瞬时尖峰——如果四张卡的尖峰碰巧对齐，就会触发电源的过流保护（OCP）。

要避免这个问题，光限功率还不够，还需要同时限制时钟频率。比如 nvidia-smi -lgc 210,1500 能有效避免触发 OCP。

最终配置

最终我选择的配置如下：

  • 主板：ASRock Rack ROMED8-2t。据我调研，这似乎是家用多 GPU 集群的热门选择。r/localllama 上很多跑多 3090 方案的人都用它，tinybox red 似乎也用了它，James Betker（nonint）的集群也是这块板。有人抱怨固件无法更新——我暂时还没尝试升级。唯一槽点是手册没有把所有 POST 错误代码都列出来，出了点小问题只能靠自己查。但它的 7 个 PCIe x16 插槽令人印象深刻——不用做通道拆分（bifurcation）就能扩展远超 4 张 GPU！
  • CPU：EPYC 7532。目前在 eBay 上相当便宜，32 核 / 64 线程。如果你的任务能有效并行化，这个核心数……相当够用。更关键的是，它有 128 条 PCIe 通道，足够跑 7 张全速 16x GPU 外加几块 NVMe。注意 TDP 是 200W，算功耗预算时得把这笔账算进去。
  • 电源：Thermaltake 1650W。这几乎是你能买到适配美式插座的最大功率电源。美国插座理论最大 1800W（15A × 120V），但实际建议上限是 1440W（80% 持续负载）。为什么不上 1400W 电源？原因很多：电源转换效率达不到 100%、接近满载运行又吵又缩短寿命、负载越接近峰值效率越低——电源都有效率曲线，离额定点越远效率越低。
  • 内存：DDR4 ECC。具体买什么型号我不方便推荐，但你需要的是 ECC RDIMM 或 ECC LRDIMM（ECC = Error Correcting Code 纠错码）。每块主板有推荐的内存兼容列表，我在 eBay 上找到了最便宜的匹配型号。最终选了 4 × 64GB，共 256GB。这已经绰绰有余，以后内存价格跌回正常水平还可以再升级到 512GB。内存速度和通道数也是需要考虑的因素——不过这些主要在用 ZeRO3 微调大模型时才重要，因为 ZeRO3 会把梯度卸载到 CPU 内存，此时你受限于内存的读写带宽。
  • GPU：4 张限功率的 3090 Ti。坦白说，我建议你优先选 3090 而不是 3090 Ti（后文会解释原因），但我运气很好，以很低的价格先买到了前两张，又不想混用不同型号。每张 3090 Ti 的 TDP 是 450W，乍一看 450 × 4 = 1800W，似乎没戏了。但通过功率限制加降频，完全可以跑。（我发布了一些辅助脚本：github.com/jbarrow/gpu-management）
  • 机箱：廉价矿机机箱。越少说越好。我选了 6 位机箱，因为它比 8 位机箱占地面积小很多，又比 12 位机箱矮很多。

与室友和平共处

如果你打算走类似的路线，我能给出的最重要建议是：留意你身边的人。如果你的爱好给他人添了负担，你有义务不当个混蛋。这样的工作站本质上是一台"带噪音的取暖器"，确实很扰人。我没有地下室，也没有"放角落不管"的地方。所以我达成的协议是：只要任何时候它太吵或太热，我就关机。我大部分批量推理都安排在夜间或者没人待在房间里的时候跑。

踩过的坑

  • 用了 3090 Ti——相比 3090，3090 Ti 的 TDP 高出一大截（450W vs 350W）。功耗的增加带来的性能提升很有限，尤其是看每瓦性能比。2022 年我从 NVIDIA 以远低于 MSRP 的价格买到了一张全新的 3090 Ti——当时整个市场的 GPU 都在溢价销售，这个"好价格"把我带上了这条路。如果重来一次，我可能会全上 EVGA FTW3 3090：EVGA FTW3 用的是两根 PCIe 8-pin 线，而不是单根 12VHPWR 线，更不容易出供电问题。
  • 犹豫了好几个好价——过程中我遇到过很多不错的价格（内存、SSD、GPU 都有），但因为当时还没有完全下决心搭建而错过了。在当前硬件价格波动剧烈的环境下，犹豫基本上是你能做的最糟的事。
  • 没有认真读手册。说真的，至少得读读主板的说明书。我就是因为没读，才发现默认一个 NVMe 插槽是禁用的，需要拔插跳线才能启用。

幸好这些错误都没有造成太大损失（当然要是我真把 3090 Ti 换成 3090，那拆装起来就麻烦大了）。

软件建议

我跑的是 Ubuntu Server + Tailscale，这样我就能从任意地方 SSH 连上机器。大部分的娱乐性质的开发工作直接在机器上用 Neovim 完成。代码通过 GitHub 同步，数据量小的用 rsync，数据量大的挂载 NAS。

至于要不要装 Proxmox 之类的虚拟化平台，我不太好建议。老实说，我考虑过搭一套 Slurm 来做作业调度，但一直没动手。

我安装了 George Hotz 的破解版 NVIDIA 驱动，它解锁了 GPU 间的 P2P 通信。如果你跑类似的方案，我非常推荐用这个驱动。

FAQ

预算更多或更少会怎么选？

预算多的话，我会选工作站卡。工作站卡带涡轮风扇，能直接塞进标准机箱里！如果预算无上限，那就是 4 张 RTX PRO Blackwell 6000 Max-Q，每张 96GB VRAM、TDP 仅 300W。

不幸的是，我的预算买不起任何 RTX PRO 卡。一张 $1600 的 RTX PRO 4000 只有 24GB VRAM，速度跟 3090 差不多但内存带宽更低。150W 的 TDP 确实很诱人，但买 4 张的花费和买 8 张 3090 差不多。如果预算更高或者对噪音和散热更在意，我倒是会把这些卡配合同样的主板和 CPU，塞进一个 XL 机箱里。

预算更紧的话不好说。我非常看重可扩展性，所以可能还是会选服务器主板 + 单条 64GB ECC 内存 + 单张 3090。这意味着以后扩展成完整的 4 卡机器时，我不用扔掉任何已有部件。

你推荐我也这么做吗？

除非你本来就有点疯，而且想让自己更疯一点。（是的。）

现在是搭建 GPU 集群的好时机吗？

不幸的是，现在是搭建家用 GPU 集群最差的时机之一。电脑硬件很贵，而且还在涨价。目前正处于内存短缺期，你需要的服务器内存大概是一年前的 3 到 5 倍，甚至更多。存储价格也涨了 2 到 3 倍，所以你可能不得不在 GPU、内存和存储之间做取舍。

但另一方面，现在也不完全是坏时机。二手市场有好 GPU 在售！作为博士生（2016-2022），我们实验室的集群主要是 1080 Ti 和 2080 Ti——11GB 的卡。那会儿训练 BERT 和图卷积网络没问题，但模型越来越大之后……

现在你能买到二手 3090，它们有 24GB VRAM。当然，5090 有 32GB、RTX PRO 6000 Blackwell 有 96GB，但 24GB 在今天已经能做很多事了。

为什么不用云计算？

为什么我不多吃沙拉、少吃美味的三明治？为什么地铁更快的时候我还骑自行车？因为我是人，我好奇，我不是一个完美的优化器，你也不应该是。这台工作站变成了一个长达数月的执念，我非常享受搭建和折腾的过程。

用两个电路不行吗？

有人建议我把电源分到两个电路上，以此绕过第一条约束。不幸的是，这违反了第二条约束——我们公寓的电路总数有限。猜猜我第一次插上的插座跟什么共用一个回路？我的烧水壶。在我跑 OCR 任务的同时烧水时，跳闸了。
