大语言模型（LLM）的快速发展使得模型评估成为 AI 领域的关键议题。本报告系统性地介绍当前主流的大模型基准测试，涵盖基础认知、推理能力、数学推理、编程能力、Agent 交互、多模态理解及专业领域等七大类别，共 30+ 个基准测试。每个基准测试配备 1-2 个具体测试用例，帮助读者深入理解各基准的测试方式和评估侧重点

第一章：基础认知与知识能力 #

1.1 MMLU - 通用知识（跨学科理解） #

MMLU（Massive Multitask Language Understanding，大规模多任务语言理解） 是 AI 领域最经典的基准测试之一，由加州大学伯克利分校研究人员于 2021 年发布。
测试内容：

  • 涵盖 57 个学科领域
  • 包含 15,908 道选择题
  • 学科范围从基础数学到专业法律、医学

典型测试用例：
【题目】以下哪种元素在元素周期表中具有最高的电负性？
（A）钠（Na） （B）钾（K） （C）氟（F） （D）钙（Ca）
【答案】C
【解析】电负性表示原子吸引电子的能力。氟是电负性最强的元素（泡利标度 3.98），远高于钠（0.93）、钾（0.82）、钙（1.00）。
另一测试用例：
【题目】根据美国宪法第一修正案，以下哪项不属于言论自由保护的范围？
（A）政治演讲 （B）宗教崇拜 （C）煽动立即暴力行动 （D）新闻报道
【答案】C
性能参考：顶级模型在 MMLU 上达到 85% 左右准确率，但由于题目相对简单，区分度正在下降。

1.2 MMLU-Pro - 增强专业知识推理 #

MMLU-Pro 是 MMLU 的增强版本，题目难度更高，更侧重专业知识的深度推理。
测试内容：

  • 在 MMLU 基础上增加题目难度
  • 加入更多需要多步骤推理的选择题
  • 减少简单事实记忆类题目

典型测试用例：
【题目】在量子力学中，若一个粒子处于叠加态 ψ = (1/√2)|↑⟩ + (1/√2)|↓⟩，测量自旋 z 分量的期望值为？
（A）ħ/2 （B）-ħ/2 （C）0 （D）ħ
【答案】C
【解析】期望值 ⟨S_z⟩ = (1/2)·(ħ/2) + (1/2)·(-ħ/2) = 0。这是自旋为 1/2 粒子的最大叠加态。
性能参考：MMLU-Pro 对提示词变化的敏感度从 MMLU 的 4-5% 降低到 2%，评估更稳定。

1.3 SimpleQA - 事实准确性 #

SimpleQA 专注于测试模型是否产生"幻觉"（hallucination），即生成与事实不符的内容。
测试内容：

  • 要求模型回答简短的事实性问题
  • 评估答案的事实准确性
  • 区分"不知道"和"胡编"

典型测试用例：
【题目】OpenAI 的 GPT-4 模型正式发布日期是什么时候？
【答案】2023 年 3 月 14 日
【评估标准】模型需要给出准确日期，错误或"我不知道"都会被记录。
另一测试用例：
【题目】特斯拉公司的 CEO（截至 2024 年）是谁？
【答案】埃隆·马斯克（Elon Musk）
【考察点】模型能否正确识别当前事实，而非过时的历史信息。

1.4 HellaSwag - 常识推理 #

HellaSwag 测试模型的日常语境理解和常识推断能力，基于"完形填空"形式。
测试内容：

  • 给出一个场景描述，要求选择最合理的句子结尾
  • 测试"渐进推理"能力
  • 题目来自 ActivityNet 视频描述

典型测试用例：
【题目】把锅放在炉子上，______。
（A）打开水龙头 （B）点燃炉子 （C）把锅装进冰箱 （D）开始洗碗
【答案】B
【解析】基于日常生活常识，把锅放在炉子上后，下一步应该是点燃炉子来加热。
测试难度：HellaSwag 的难点在于干扰选项与正确答案在表面上看似合理，需要更深层的语境理解。

1.5 Winogrande - 语义理解 #

Winogrande 基于 Winograd Schema Challenge，测试语言模型的语言理解和指代消解能力。
测试内容：

  • 解决句子中的歧义指代问题
  • 测试语言深层理解而非表面模式匹配
  • 涵盖 44 种不同类型的问题

典型测试用例：
【题目】钥匙掉了，因为______太矮了，看不到它。
（A）桌子 （B）他
【答案】B
【解析】这句话的关键是理解因果关系。"他"指代人，人太矮所以看不到掉在地方的钥匙。这个测试考察模型是否能正确理解语境中的指代关系。

2.1 GPQA - 科学推理（研究生级） #

GPQA（Graduate-Level Google-Proof Q&A，研究生级问答基准） 由 Google DeepMind 发布，测试研究生水平的科学理解与推理能力。
测试内容：

  • 涵盖生物学、化学、物理学、数学等学科
  • 题目难度相当于研究生资格考试
  • 需要深入的专业知识推理

典型测试用例：
【题目】在真空中，一个电子以 v = 0.9c 的速度运动（c 为光速），其动能约为多少？（电子质量 mₑ = 9.1×10⁻³¹ kg，电荷 e = 1.6×10⁻¹⁹ C）
（A）8.2×10⁻¹⁴ J （B）1.1×10⁻¹³ J （C）5.5×10⁻¹⁴ J （D）2.2×10⁻¹³ J
【答案】B
【解析】相对论动能公式：K = (γ - 1)mc²，其中 γ = 1/√(1 - v²/c²) = 1/√(1 - 0.81) ≈ 2.29
K = 1.29 × 9.1×10⁻³¹ × (3×10⁸)² ≈ 1.1×10⁻¹³ J
考察点：需要运用相对论力学而非经典力学，且涉及单位换算。

2.2 GPQA Diamond - 顶级科学推理 #

GPQA Diamond 是 GPQA 的高难度子集，仅包含最难的题目，是顶级模型的区分器。
典型测试用例：
【题目】在量子场论中，计算以下进程的 S 矩阵元：一维盒子中的两个相同费米子相互散射，初始动量分别为 p₁ 和 p₂。
（A）S = δ(p₁ - p₃) - δ(p₁ - p₄) （B）S = δ(p₁ - p₃) + δ(p₁ - p₄) （C）S = δ(p₁ - p₃)δ(p₂ - p₄) （D）S = 0
【答案】A
【解析】由于费米子的交换对称性，两个相同费米子的波函数在交换时需要变号，因此散射振幅包含符号因子。

2.3 ARC-AGI - 抽象推理（AGI 导向） #

ARC-AGI（Abstraction and Reasoning Corpus for AGI） 由 Keras 作者 François Chollet 创建，被视为 AGI 导向的基准测试。
测试内容：

  • 图形变换题目（类似 IQ 测试）
  • 考察抽象推理和泛化能力
  • 需要从少量示例中学习规则

典型测试用例：
【题目】给定输入输出对：
输入：3×3 网格，左上角为红色方块，其余为白色 输出：同样的 3×3 网格，但红色方块移动到右下角
当输入变为 5×5 网格，左上角为红色方块时，输出应该是？
【答案】5×5 网格，红色方块在右下角
【解析】测试模型是否能理解"将红色方块从左上角移动到右下角"的抽象规则，并泛化到不同尺寸的输入。
难度说明：即使是 GPT-4 等顶级模型，在 ARC-AGI 上的表现也远不如人类，2025 年最佳模型仅能达到 68% 准确率。

2.4 BIG-Bench Hard（BBH）- 复杂推理 #

BIG-Bench Hard 是 Google BIG-Bench 基准中最难的任务子集，专注于需要"逐步推理"的复杂问题。
测试内容：

  • 涵盖 23 个高难度任务
  • 包括逻辑推理、语义理解等
  • 不能通过"捷径"或模式匹配解决

典型测试用例：
【题目】找出下一个数字：2, 6, 12, 20, 30, ___
（A）36 （B）40 （C）42 （D）44
【答案】C（42）
【解析】数列规律：1×2=2，2×3=6，3×4=12，4×5=20，5×6=30，6×7=42。通项公式为 n×(n+1)。
另一测试用例：
【题目】如果有 5 个人，每个人要么总是说真话，要么总是说假话。A 说"B 是说假话的"，B 说"C 是说真话的"，C 说"A 和 B 至少有一个说真话"。已知只有一个人说真话，谁在说真话？
【答案】B
【解析】需要逻辑推理和假设验证，是典型的逻辑谜题。

2.5 Humanity's Last Exam - 极限推理 #

Humanity's Last Exam（人类最后的考试） 是目前最接近人类知识极限的基准，涵盖极其困难的专业问题。
测试内容：

  • 专家级别的深度问题
  • 需要多学科知识整合
  • 很多问题即使是人类专家也需要大量时间思考

典型测试用例：
【题目】在朗兰兹纲领的背景下，解释为何椭圆曲线的 L-函数在 s=1 处的行为与该曲线的算术性质有深刻联系，并给出一个具体的例子说明这种联系。
【答案】（略，答案为长篇论述题）
【解析】这需要深厚的数论和代数几何背景知识，属于数学前沿领域。

3.1 GSM8K - 基础数学 #

GSM8K（Grade School Math 8K） 测试小学到初中水平的数学应用题。
测试内容：

  • 8,500 道小学数学应用题
  • 需要逐步推理和计算
  • 答案通常是整数

典型测试用例：
【题目】小明有 15 个苹果。他把苹果的 1/3 送给了小红，又买了 5 个新的苹果。现在小明有多少个苹果？
【答案】15 - 5 + 5 = 15 个
【解析】15 × (1/3) = 5 个送出去，15 - 5 = 10 个，10 + 5 = 15 个。
另一测试用例：
【题目】一本书有 240 页。小华第一天读了全书的 1/4，第二天读了剩下的 1/3，第三天从第几页开始读？
【答案】120 + 1 = 121 页
【解析】第一天读 240×1/4=60 页，剩 180 页。第二天读 180×1/3=60 页。已读 120 页，第三天从 121 页开始。

3.2 MATH - 高级数学 #

MATH 基准包含 12,500 道中学数学竞赛级别的题目，涵盖代数、几何、数论等。
测试内容：

  • 竞赛级数学题目
  • 需要 LaTeX 格式的解题步骤
  • 包含证明题和复杂计算

典型测试用例：
【题目】求函数 f(x) = x³ - 3x² + 2 在 x = 1 处的二阶导数。
【答案】f''(1) = 6
【解析】f'(x) = 3x² - 6x，f''(x) = 6x - 6，f''(1) = 6×1 - 6 = 0？错误！
正确：f'(x) = 3x² - 6x，f''(x) = 6x - 6。等等，f(x) = x³ - 3x² + 2
f'(x) = 3x² - 6x f''(x) = 6x - 6
f''(1) = 6×1 - 6 = 0
（正确答案应为 0）
【另一测试用例】：
【题目】在△ABC 中，∠A = 60°，AB = 4，AC = 6，求 BC 的取值范围。
【答案】|AC - AB| < BC < AB + AC，即 2 < BC < 10
【解析】三角形两边之和大于第三边，两边之差小于第三边。

3.3 MATH-500 - 高难数学 #

MATH-500 是 MATH 基准中最难的 500 道题目的子集。
典型测试用例：
【题目】求满足以下条件的整数 n：n² + n 能被 100 整除，且 n² - 1 能被 100 整除。
【答案】n ≡ 1 mod 100 或 n ≡ 99 mod 100
【解析】需要求解同余方程组，属于数论范畴。

3.4 AIME - 竞赛数学 #

AIME（American Invitational Mathematics Examination） 是美国数学邀请赛题目，难度等同于顶级数学竞赛。
典型测试用例：
【题目】计算 1² + 2² + 3² + ... + 2024² 的末三位数字。
【答案】776
【解析】使用求和公式：1²+2²+...+n² = n(n+1)(2n+1)/6
代入 n = 2024，计算后取末三位。

4.1 HumanEval - 代码生成 #

HumanEval 由 OpenAI 发布，是评估代码生成能力的经典基准。
测试内容：

  • 164 道编程问题
  • 每道题包含函数签名、文档字符串和测试用例
  • 需要生成可运行的 Python 代码

典型测试用例：
【题目】编写一个函数 second_largest(nums)，输入一个整数列表（至少包含两个不同元素），返回第二大的数。

def second_largest(nums):
    """
    返回列表中第二大的数
    
    示例:
    >>> second_largest([5, 3, 1, 4, 2])
    4
    >>> second_largest([10, 10, 5, 5, 1])
    5
    """
    # 请编写代码
    unique_nums = sorted(set(nums), reverse=True)
    return unique_nums[1] if len(unique_nums) >= 2 else None

另一测试用例：
【题目】编写函数 is_palindrome(s)，判断字符串是否为回文（忽略大小写和非字母字符）。

def is_palindrome(s):
    """
    >>> is_palindrome("A man, a plan, a canal: Panama")
    True
    >>> is_palindrome("race a car")
    False
    """
    cleaned = ''.join(c.lower() for c in s if c.isalpha())
    return cleaned == cleaned[::-1]

4.2 MBPP - 基础编程 #

MBPP（Mostly Basic Python Problems） 包含 1,000 道基础 Python 编程问题。
典型测试用例：
【题目】编写函数计算列表中所有偶数的和。

def sum_of_evens(lst):
    """
    返回列表中所有偶数的和
    
    >>> sum_of_evens([1, 2, 3, 4, 5, 6])
    12
    >>> sum_of_evens([1, 3, 5])
    0
    """
    return sum(x for x in lst if x % 2 == 0)

import numpy as np

def gradient_descent(X, y, lr=0.01, epochs=1000):
    m, b = 0, 0
    n = len(y)
    for _ in range(epochs):
        y_pred = m*X + b
        dm = (-2/n) * sum(X * (y - y_pred))
        db = (-2/n) * sum(y - y_pred)
        m -= lr * dm
        b -= lr * db
    return m, b
