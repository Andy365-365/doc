NUMA 优化

参数描述环境变量
--numa TYPE 尝试在某些 NUMA 系统上提供帮助的优化：
distribute：在所有节点上均匀分布执行
isolate：仅在启动执行所在节点的 CPU 上生成线程
numactl：使用 numactl 提供的 CPU 映射

如果之前未使用此参数运行过，建议在使用前先清除系统页缓存。
参见：Issue #1437		 LLAMA_ARG_NUMA
