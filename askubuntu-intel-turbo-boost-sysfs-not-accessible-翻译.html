问题 无法通过 sysfs 关闭 Intel Turbo Boost

我尝试按照 这篇回答（关于「在 Ubuntu 中禁用 Intel Turbo Boost」）中的步骤操作：

首先查看当前驱动：

cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_driver
intel_pstate
intel_pstate
intel_pstate
intel_pstate

然后查询 turbo 的启用/禁用状态：

cat /sys/devices/system/cpu/intel_pstate/no_turbo
1

这表示 turbo 是开启的。

但尝试禁用它时，提示「操作不允许」：

echo "0" | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo
[sudo] password for cipeos:
0
tee: /sys/devices/system/cpu/intel_pstate/no_turbo: Operation not permitted

尝试回答下方评论中的建议（sudo echo "0" | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo），结果一样。即使先执行 sudo su 再操作，仍然报同样的错。

尝试用编辑器手动打开该文件：

sudo gedit /sys/devices/system/cpu/intel_pstate/no_turbo

文件内容只有一行：

1

将其改为 0 并保存时，提示：「无法保存文件 "/sys/devices/system/cpu/intel_pstate/no_turbo"。您没有保存此文件所需的权限。请确认路径是否正确，然后重试。」

✓ 最佳答案 15 票

Doug Smythies 回答：

Turbo 启用/禁用标志可能会产生误导。以下是内核源码树中 Documentation/cpu-freq/intel-pstate.txt 的摘录：

Sysfs will show :
        max_perf_pct:100, which corresponds to 1 core ratio
        min_perf_pct:24, max_efficiency_ratio / max 1 Core ratio
        no_turbo:0, turbo is not disabled
        num_pstates:26 = (max 1 Core ratio - Max Efficiency Ratio + 1)
        turbo_pct:39 = (max 1 core ratio - max non turbo ratio) / num_pstates

因此，在这个案例中，"1" 表示 turbo 已被禁用。

对于大多数计算机，turbo 可以在 BIOS 中禁用。如果 turbo 在 BIOS 层面被禁用，那么就无法通过 Sysfs 覆盖该标志。下面给出两种情况的对比：

示例 1（BIOS 中已禁用 turbo）：

$ echo 0 | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo
0
tee: /sys/devices/system/cpu/intel_pstate/no_turbo: Operation not permitted

示例 2（BIOS 中已启用 turbo）：

$ cat /sys/devices/system/cpu/intel_pstate/no_turbo
1
$ echo 0 | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo
0
$ cat /sys/devices/system/cpu/intel_pstate/no_turbo
0

💡 核心要点总结

关键理解：no_turbo 文件的值含义与直觉相反——

  • 0 = turbo 未被禁用（即 turbo 处于启用状态）
  • 1 = turbo 已被禁用

提问者看到值为 1，误以为 turbo 是开启的，实际上 turbo 已经被禁用了。

为什么无法写入：如果 turbo 在 BIOS 层面被禁用，内核会将 no_turbo 设为只读，此时即使以 root 权限也无法通过 sysfs 修改它。反之，如果 BIOS 中 turbo 是启用的，则可以通过 sysfs 动态开关。

解决方案：如果想通过 sysfs 控制 turbo，需要进入 BIOS 确保 turbo 功能处于启用状态，然后就可以在系统中通过该文件动态切换了。
